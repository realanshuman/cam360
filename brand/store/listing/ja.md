# Cam360 store listing: 日本語 (`ja`)

Paste into the Chrome Web Store dashboard: open the item, then the Store
listing tab, pick **日本語** in the language menu (add it with Manage
languages the first time), and fill the fields below. The same text works for
the Firefox add-on listing on addons.mozilla.org.

## Summary

Not typed into the dashboard. The store reads it from the extension, from

## Detailed description

```
新しいカメラを買わなくても、どのビデオ通話でももっときれいに。

Cam360 は、Web カメラと通話に使うウェブサイトの間で働きます。ポップアップを開いてスライダーを動かすだけで、変更がすぐに映像に反映されます。アカウントも登録も、面倒な設定も要りません。

できること

- 背景をぼかす、または単色・シーン・自分の写真に差し替える
- 明るさ、コントラスト、ワンクリックの暗所補正で暗い照明を補正する
- 左右反転、上下反転、回転、ズームで構図を整える
- 目や髪、背後の部屋はくっきりのまま、肌だけをなめらかにする
- 席を外すときは映像を静止するか、「すぐに戻ります」の画面を表示する
- 名前、ロゴ、時計を映像の好きな隅に表示する
- 相手に見えている映像をそのままスナップショットで保存する

選ばれる理由

- どこでも使えます。Google Meet、Discord、ブラウザ版 Zoom、Whereby、Jitsi など、カメラを使うあらゆるサイトで動きます。一度の設定がすべてに適用されます。
- プライバシーを守ります。映像はお使いのパソコン上で処理され、そのままサイトに渡されます。Cam360 は通信を一切行わず、分析ツールもなく、録画やアップロードもしません。背景用の AI モデルも拡張機能に同梱されています。
- すぐに反映されます。通話中でも小さなパネル（Alt C で表示）から変更でき、相手にもその場で反映されます。
- 無料です。有料プランも試用期間もなく、アカウントの作成も不要です。
- 日本語に対応しています。英語、スペイン語、ポルトガル語、フランス語、ドイツ語でも使えます。

仕組み

サイトがカメラを要求すると、Cam360 が先に応答し、お使いのデバイス上で各フレームに設定を適用して、完成した映像をサイトに渡します。サイトからは通常のカメラと同じに見えるため、Cam360 への対応は必要ありません。

注意: この拡張機能はブラウザ内のウェブサイトで動作します。Discord や Zoom のデスクトップアプリには、どのブラウザ拡張機能も届きません。これらのアプリはウェブ版をお使いください。
```
