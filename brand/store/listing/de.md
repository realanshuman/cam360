# Cam360 store listing: Deutsch (`de`)

Paste into the Chrome Web Store dashboard: open the item, then the Store
listing tab, pick **Deutsch** in the language menu (add it with Manage
languages the first time), and fill the fields below. The same text works for
the Firefox add-on listing on addons.mozilla.org.

## Summary

Not typed into the dashboard. The store reads it from the extension, from
`_locales/de/messages.json` (`extDescription`), so it ships with the
package. 131 of 132 characters.

```
Sieh in jedem Videoanruf besser aus: Hintergrund unscharf oder neu, besseres Licht, Spiegeln, Zoom. Für Meet, Discord, Zoom & mehr.
```

## Detailed description

```
Sieh in jedem Videoanruf besser aus, ohne eine neue Kamera zu kaufen.

Cam360 sitzt zwischen deiner Webcam und der Website, über die du telefonierst. Öffne das Popup, bewege einen Regler, und die Änderung erscheint sofort in deinem Video. Kein Konto, keine Anmeldung, nichts einzurichten.

WAS DU TUN KANNST

- Den Hintergrund unscharf machen oder durch eine Farbe, eine Szene oder dein eigenes Foto ersetzen
- Schlechtes Licht mit Helligkeit, Kontrast und einem Klick für wenig Licht korrigieren
- Die Kamera spiegeln, kippen, drehen und zoomen, bis der Bildausschnitt passt
- Die Haut glätten, während Augen, Haare und der Raum hinter dir scharf bleiben
- Das Bild einfrieren oder eine „Bin gleich zurück“-Karte zeigen, wenn du kurz weg bist
- Deinen Namen, ein Logo oder eine Live-Uhr in dein Video einblenden, in der Ecke deiner Wahl
- Einen Schnappschuss von genau dem speichern, was die anderen sehen

WARUM MAN ES INSTALLIERT

- Es funktioniert überall. Google Meet, Discord, Zoom im Browser, Whereby, Jitsi und jede andere Website, die nach deiner Kamera fragt. Eine Einrichtung für alle.
- Es ist privat. Dein Video wird auf deinem eigenen Computer verarbeitet und direkt an die Website übergeben. Cam360 stellt keine Netzwerkanfragen, hat keine Analyse und nimmt nie etwas auf oder lädt etwas hoch. Sogar das KI-Modell für den Hintergrund steckt in der Erweiterung selbst.
- Es wirkt sofort. Ändere alles mitten im Anruf über ein kleines Panel (Alt C drücken), und alle sehen es live.
- Es ist kostenlos. Kein Bezahlmodell, keine Testphase, kein Konto.
- Es spricht deine Sprache: Deutsch, Englisch, Spanisch, Portugiesisch, Französisch und Japanisch.

SO FUNKTIONIERT ES

Wenn eine Website nach deiner Kamera fragt, antwortet Cam360 zuerst, wendet deine Einstellungen auf jedes Bild direkt auf deinem Gerät an und gibt das fertige Video an die Website weiter. Die Website behandelt es wie eine normale Kamera. Sie muss Cam360 also nicht unterstützen.

Hinweis: Diese Erweiterung funktioniert auf Websites in deinem Browser. Desktop-Apps wie die Desktop-Versionen von Discord oder Zoom kann keine Browsererweiterung erreichen. Nutze dort die Webversion.
```
