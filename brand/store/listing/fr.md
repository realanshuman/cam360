# Cam360 store listing: Français (`fr`)

Paste into the Chrome Web Store dashboard: open the item, then the Store
listing tab, pick **Français** in the language menu (add it with Manage
languages the first time), and fill the fields below. The same text works for
the Firefox add-on listing on addons.mozilla.org.

## Summary

Not typed into the dashboard. The store reads it from the extension, from
`_locales/fr/messages.json` (`extDescription`), so it ships with the
package. 131 of 132 characters.

```
Soyez à votre avantage en visio. Floutez ou changez l’arrière-plan, corrigez la lumière, miroir, zoom. Meet, Discord, Zoom et plus.
```

## Detailed description

```
Soyez à votre avantage dans chaque appel vidéo, sans acheter de nouvelle caméra.

Cam360 se place entre votre webcam et le site depuis lequel vous appelez. Ouvrez la fenêtre, déplacez un curseur, et le changement apparaît aussitôt dans votre vidéo. Pas de compte, pas d’inscription, rien à configurer.

CE QUE VOUS POUVEZ FAIRE

- Flouter l’arrière-plan, ou le remplacer par une couleur, une scène ou votre propre photo
- Corriger un mauvais éclairage avec la luminosité, le contraste et un mode faible lumière en un clic
- Mettre en miroir, retourner, faire pivoter et zoomer jusqu’à obtenir le bon cadrage
- Lisser la peau tandis que vos yeux, vos cheveux et la pièce derrière vous restent nets
- Figer l’image ou afficher un carton « Je reviens tout de suite » quand vous vous absentez
- Ajouter votre nom, un logo ou une horloge en direct à votre vidéo, dans le coin de votre choix
- Enregistrer une capture exacte de ce que voient les autres

POURQUOI ON L’INSTALLE

- Il fonctionne partout. Google Meet, Discord, Zoom dans le navigateur, Whereby, Jitsi et tout autre site qui demande votre caméra. Un seul réglage pour tous.
- Il est privé. Votre vidéo est traitée sur votre propre ordinateur et transmise directement au site. Cam360 ne fait aucune requête réseau, n’a aucune statistique, et n’enregistre ni n’envoie jamais rien. Même le modèle d’IA pour l’arrière-plan est inclus dans l’extension.
- Il est instantané. Modifiez n’importe quoi en plein appel depuis un petit panneau (appuyez sur Alt C) et tout le monde le voit en direct.
- Il est gratuit. Pas de version payante, pas d’essai, pas de compte à créer.
- Il parle votre langue : français, anglais, espagnol, portugais, allemand et japonais.

COMMENT ÇA MARCHE

Quand un site demande votre caméra, Cam360 répond en premier, applique vos réglages à chaque image sur votre appareil, puis transmet la vidéo finale au site. Le site la traite comme une caméra ordinaire. Il n’a donc rien à prendre en charge pour que Cam360 fonctionne.

Remarque : cette extension fonctionne sur les sites web de votre navigateur. Les applications de bureau, comme Discord ou Zoom pour ordinateur, sont hors de portée de toute extension de navigateur. Utilisez la version web de ces applications.
```
